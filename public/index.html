Qoder Trial Injector

Paste Personal Access Token → auto-inject trial using IDE mode (type=6, v0.2.11)

Get PAT from: qoder.com → Settings → Developer → Personal Access Tokens

How it works
Step 1POST /api/v1/jobToken/exchange — exchange PAT for auth token
Step 2GET /api/v1/userinfo — trigger trial grant (no MachineToken)
Step 3GET /api/v2/user/plan — check plan status
Step 4GET /api/v2/quota/usage — check credits
VM CheckSKIP /api/v3/user/status — not called
